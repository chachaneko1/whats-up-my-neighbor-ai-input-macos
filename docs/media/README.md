| 檔案 | 來源 |
|---|---|
| `greeting.gif` | `build/cat-render/greeting-frame-00…29.png`，10 fps，寬 440px |
| `desktop-pet-walking.gif` | `build/cat-render/desktop-pet/walking-cycle/right-0…15.png`，12 fps，放大到 256px |

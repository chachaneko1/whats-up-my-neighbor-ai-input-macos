# 貓咪抓起／放下動畫規範

2026-10-25：依使用者要求建立。最低動作密度以已留存的 R4/R6 原畫播放規則為基準；歷史主觀參考版本正向使用者確認。規格與測試通過不代表視覺已驗收。

## 時間與有效影格

| 項目 | 基準 |
| --- | --- |
| 有效姿勢更新 | 每秒20張不同、連續的完整姿勢作為最低基準；一般播放間隔50ms |
| 完整放下 | 800ms，16次連續姿勢推進；含t=0起始與t=800ms終點共17個取樣節點 |
| 抓起 | 保留既有R6的850ms與08→10已記錄的特殊時點，不在放下修正中順便改動 |
| 螢幕回呼 | 30/60/120Hz依絕對時間選同一姿勢；螢幕刷新率不等於素材張數 |
| 靜止 | 完成後可長時間保持終點；持握／靜止停留不計入移動影格密度 |

20Hz只是最低動作密度，不保證平滑；相鄰圖的姿勢、前腳位移及速度仍需逐格覆核。若50ms圖間跳動仍大，補足連續完整姿勢；不以重複圖、拉長每格停留、加大檔案FPS或單純增加display callback假裝增加有效影格。刪除回彈後缺少過渡圖，必須先補足／找到合適原畫，不能把剩餘8次推進各停100ms來湊800ms。

## 姿勢與視覺

- 動作依序為持握→前腳支撐→身體落下→坐定。坐定後不再起身或重播回彈。
- 保留原生source35坐姿的大小及位置；不把較小的source00直接換作原生終點。
- 保留完整貓身、頭臉、前後爪與尾巴；固定畫布、抓取錨點及共用縮放，不以每格縮放、拆身體、混色重影或未核准的幾何補間掩蓋缺圖。
- 放開首圖等於最後持握圖；中途重抓沿目前姿勢返回；不重置到另一張坐姿。
- 黑貓與三花先並排覆核，再檢查九種毛色，不改動毛色座標或現存美術來迴避時序問題。

## 驗收與更新

1. 查回歷史GIF、原畫、生成／切分manifest及實際時間表，分開記錄GIF編碼格數、有效姿勢數與螢幕刷新率。完整互動GIF包含靜止與示意游標，不能用GIF總格數當作放下素材數。
2. 對照正常速度、慢速與逐格圖，檢查接縫、腳部位移、頭身大小、姿勢是否連續、終點是否靜止。若未經使用者指定，R3程式補間只能作歷史比較，不能直接替代R6原畫。
3. 原生事件路徑驗證完整／短抓放、中途重抓、Reduce Motion、30/60/120Hz、busy gate與焦點；離線測試不證明主觀順暢。
4. 本機預覽與使用者實際觀感通過後，才更新現用App。更新前比對修正commit是否真的在目標來源／安裝包，保留相容簽章、原路徑、現有設定及舊App備份。
5. 建置／測試期間凍結所有輸入檔，包含註解；需要改動就先停止執行、改完再重跑。
6. 分別記錄本機修正版、PR/main、公開Release與使用者驗收。已被回報卡頓的版本即使測試綠燈，仍不得標記完成或發布。

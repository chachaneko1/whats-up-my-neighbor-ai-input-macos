# Mac 選單列選貓預覽

此分支在 Mac App 選單列的「放出小黑貓」下方加入「選擇貓咪花色」子選單。九種花色與目前選項直接列在選單中；點選後只修改這台 Mac 的 `cat.config.json`，並詢問是否重新啟動。沒有登入、付費或網站同步。

選單保留問候、字型、圖片等原有設定，將 version 1 升到 version 2。若現有設定含自訂部位或花紋、格式無效，或設定檔不是一般檔案，選單會停止而不覆寫。自訂圖片仍優先用於錄音浮窗與問候；桌面貓會依選擇換色。選擇「稍後」時，新花色會在下次開啟 App 後生效。

可點選的網頁示意：`Previews/CatCoatMenu/index.html`。按「選擇貓咪花色」可展開九個選項，再點選花色檢查選中狀態與提示。它沿用目前 macOS 選單的半透明玻璃視覺，但只模擬操作，不讀寫個人設定，也不會重新啟動 App。真正的 Mac 選單使用系統 `NSMenu` 外觀；這次沒有另做一套選單主題。另有隔離原生預覽程式 `Previews/CatCoatMenu/build-preview.sh`。完整 App 可用 `scripts/build.sh` 建置於本 worktree 的 `build/`。本分支沒有安裝、合併或發布。

本機驗證：`scripts/test-cat.sh` 的設定、九種選單項目與既有 AppKit 檢查通過；雙架構 App 建置及簽章檢查通過。

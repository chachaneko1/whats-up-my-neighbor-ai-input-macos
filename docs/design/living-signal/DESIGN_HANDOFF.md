## 設計理念

**把語音輸入元件本身變成一隻貓。**

使用者最初提出小黑貓、慵懶性格、語音輸入聲波、Logo、字典修改及耳朵／尾巴／搔癢互動。看過立體與剪影版本後，進一步要求「再抽象化一點，多用符號」，並具體提出聲波在貓咪耳朵之間流動、叉號與勾號跟貓咪結合。Living Signal 因此以極少量輪廓同時表達品牌與操作。

| 視覺元素 | 設計意義 | 實作規則 |
| --- | --- | --- |
| 黑色貓頭剪影 | 平靜、慵懶、有個性；輪廓縮小後仍易認 | 保留寬而圓潤的頭部與兩個三角貓耳，減少毛髮及立體細節 |
| 耳間聲波 | 貓咪正在聆聽；聲音讓輪廓活起來 | 聲波與額頭相連，耳朵框住變化區；音量變化以平滑方式流動 |
| 左眼叉號 | 把「取消」融入角色表情 | 保持清楚的 X、固定位置及足夠點擊範圍；輔助標籤「取消錄音」 |
| 右眼勾號 | 把「結束錄音並辨識」融入角色表情 | 保持清楚的勾形和固定位置；不將這個動作誤標為已確認辨識內容 |
| 短橫嘴巴 | 克制、慵懶的表情；讓功能符號仍像一張貓臉 | 保持小、平、安靜，不新增多餘表情線條 |
| 黑、暖白、少量薄荷綠 | 清楚輪廓，讓狀態重點可辨識 | 黑白是主體，薄荷綠只用於狀態或操作回饋；不以顏色單獨傳達訊息 |

## 應保留的造型特徵

1. 貓耳、頭型、聲波是同一個形體，視覺上有連接。
2. 左 X、右勾組成雙眼；兩個符號都容易辨認和點選。
3. 波形集中在兩耳之間；控制項不跟著波形晃動。
4. 簡潔的黑色剪影與少量留白，不回到寫實毛髮或複雜角色插畫。
5. Logo、浮窗與字典的品牌標記沿用同一組輪廓與比例。

## 動態理念

**2026-10-14 使用者修訂：安靜時頭頂保持平整。** 兩耳之間不保留鋸齒或低矮聲波柱，避免像梳子。只有說話且音量非零時才出現起伏；零音量、準備、處理、取消、完成及錯誤狀態都使用平整輪廓。此決策優先於上方早期概念圖的安靜分鏡，也適用於互動預覽與匯出的動態展示。

修訂後的 [動態展示 GIF](demo-assets/living-signal-flat-idle.gif) 已由瀏覽器匯出並保存，為 6 秒循環的模擬音量展示，不是真實收音或轉錄驗證。互動預覽已檢查安靜、零音量、說話及完成狀態；此紀錄不代表整個 App 已完成驗收。

聲音流動是主要動作；貓咪動作是次要回饋。開始錄音可輕抬耳朵，說話時耳間波形依音量變化，停止說話後平順降低。取消及完成按鈕的位置與可點區域始終固定。處理中改成處理狀態，不繼續假裝收音；沒有音訊時不播放虛構的大幅波形。

原始需求中的搖尾巴、搔癢與伸懶腰可保留在後續角色互動探索，但不強行增加到這個極簡錄音元件。是否加入須以不影響目前輪廓及操作清楚度為準。

「減少動態效果」時保留靜態輪廓、簡單音量與狀態文字。此處聲波是音量／時間的視覺反應，不代表身份聲紋辨識、辨識進度或辨識準確度。

## UI 與功能範圍

- **2026-10-14 操作回饋修訂：**左眼取消在滑鼠移入或鍵盤聚焦時呈現柔紅色底光、外框與「取消錄音」提示；右眼完成使用薄荷綠及「完成錄音」提示。離開後回復黑白貓臉，按壓時底色加深，按鈕位置不動。處理中的左眼改為「取消處理」；停用按鈕不亮起。顏色同時搭配 X／勾號與文字，避免只靠色彩辨識操作。這些效果已實作於瀏覽器原型，正式 App 尚未整合。

- 字典：已加入、待確認、搜尋、新增、修改、啟停、確認候選與拒絕候選；「提供提示」不等同辨識命中。

- 待確認：實際大小、細部比例、動態速度，以及字典畫面整體搭配；滑入／聚焦的配色與操作語意已依使用者要求實作，外觀可再依回饋調整。

# 個人字典：貓咪漫畫提示

2026-10-15 使用者選定：奶油黃泡泡、黑色輪廓，像貓咪漫畫。此規則只套用字典提示，不改動錄音眼睛與主品牌資產。

## 配色與閱讀

- 不透明奶油黃 `#FFF1C9` 是泡泡與貓咪底座；墨黑沿用 `NekoAppearance.ink`，用於文字與2點輪廓。
- 修正詞使用黑色粗體，背後以暖黃 `#FFD66F` 畫記；相同暖黃用於「不加入」。此泡泡不使用綠色。
- 原黑貓圖保持原樣，縮為72×54點，放在76×56點的同色底座內；短尾巴連到嘴部高度。
- 所有文字都在實色底上，後方視窗的顏色不參與文字對比。黑字對奶油黃15.04:1，對暖黃12.16:1。

## 比例

- 整組寬480點，短詞高136點；兩／三行問句增為160／184點。
- 正文17點、行高24；輔助倒數13點；按鈕文字14點。字級沒有跟著框體縮小。
- 上方是問句，下方單一操作排：倒數文字與140×3點短進度線在左，90×44點「不加入」在右。
- 顯示前依實際文字換行決定高度；倒數或暫停文字不改尺寸。框線負責界定形狀，不另加視窗陰影。

## 互動

可見並完成進場後開始六秒倒數；指標停留在整組提示上時暫停，移開後延續餘時，最後至少留一秒。隱藏、切換目標或繼續修改時維持原取消規則。預覽不寫入字典。

沿用0.18秒輕微位移／淡入與系統減少動態效果，不新增聲音、循環動畫或引導文字。

## 最新方向

- 角色以符號構成：貓耳、少量眼睛／操作線條與聲波，不採毛髮或立體角色。
- 聲波是耳朵之間的連接或輪廓，讓整個輸入元件呈現貓咪形象。
- 左側叉號代表取消、右側勾號代表結束錄音並辨識；兩者整合成貓咪的眼睛或形狀切口。
- 正式錄音狀態的勾號必須有「結束錄音並辨識」的輔助標籤。概念圖中的「完成」只是簡短展示文案，不能把它解讀成已確認辨識內容。
- 此處聲波指麥克風音量隨時間的視覺反應，不新增聲紋身份辨識功能。

## 動態設計提案

依 2026-10-14 使用者修訂，安靜時耳間輪廓保持平整，不保留低矮的聲波柱或鋸齒。只有說話且音量非零時才呈現起伏；零音量、處理、取消及完成後回到平整輪廓。錄音狀態另外以可見文字或圖示顯示，避免把平整輪廓誤讀成沒有開始錄音。早期概念圖保留作歷程，動態行為以此修訂為準。

耳朵可以在開始錄音時小幅抬起或輕抖；取消與完成符號的中心位置、可點範圍保持固定。滑入或鍵盤聚焦時，以背景或描邊提示操作區域，維持可辨識的 X 與勾形，不因趣味變形成不明按鈕。

處理中停止顯示收音波形，改用適當的狀態指示；成功、失敗仍遵循上一版 UI_DESIGN.md 的真實事件與文字規則。減少動態效果時停止線條平移與耳朵動作，使用簡單音量強弱及明確狀態文字。

分鏡裡的 quiet、voice、settle 是同一元件的姿勢示意，不是可直接播放的影格序列。Logo 與錄音介面先選定同一個輪廓，之後再做一致的精修版及小尺寸辨識檢查。

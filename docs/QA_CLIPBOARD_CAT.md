# 剪貼簿與九種桌面貓 QA

這份測試版把已存在於另一個分支的 Command＋V 歷史手勢接回 App，並讓已合併的毛色選單直接更新桌面貓。正式版 1.4.5 尚未包含；一般「檢查更新」仍會取得正式版。

## 安裝與確認

1. 從本次 PR 已成功的 **Build** 工作下載 `macos-development-installer` artifact，解開外層 ZIP，再解開裡面的 App 安裝 ZIP。
2. 對 `安裝.command` 按右鍵選「打開」。安裝工具會沿用現有位置與設定；完成後終端機視窗可關閉，App 會獨立執行。
3. 點選單列的小黑貓。版本下方應有 **「QA 測試版 · 來源編號」**，用它核對下載的 PR commit。正式版版本／build 編號未因 QA 改寫。
4. 不要同時開啟兩份 App。若 macOS 再次要求輔助使用權限，授權後回到原輸入 App；手勢未啟用時仍可用 `⌃⌥V` 或選單開啟歷史。

開發包使用現有的 ad-hoc 簽章流程，沒有 Apple 公證；第一次開啟可能出現 macOS 確認。它共用原本的 App 身分、偏好設定與本機資料，所以切換的毛色與桌面顯示選擇會保留。GitHub 的安裝包 artifact 保留七天。

## 剪貼簿的實際操作

先依序複製三段容易辨認的文字，例如「第一筆」、「第二筆」、「第三筆」，再把游標放到可輸入的文字欄位。

| 操作 | 預期結果 |
|---|---|
| 一般短按 `⌘V`，放開 V | 貼入目前內容一次，不開歷史清單 |
| 按住 `⌘V`，再按 `↑` 或 `↓` | 開啟歷史，先選上一筆；輸入框不會先多貼一次最新內容 |
| 開啟清單後繼續按 `↑`／`↓` | 移動選取，可以繼續按住或放開 Command／V |
| 只放開 Command／V | 清單留著，不貼上 |
| 按 Enter 或點選一筆 | 放開確認按鍵後貼入選取文字一次，聊天訊息不會送出 |
| 按 Esc | 關閉清單，不貼入文字 |
| 按 `⌃⌥V` 或點選單「剪貼簿歷史」 | 同樣能開清單，原有自訂快捷鍵繼續有效 |

在你平常使用的瀏覽器文字欄與編輯器各試一次。這個手勢由「Command＋V 加方向鍵」觸發，單純長按等待不會自動展開。若焦點已改變或不能驗證，選取文字只會留在剪貼簿，回到目標欄位短按 `⌘V` 即可。

## 把九種貓直接放到桌面

點選單列 → **「選擇貓咪花色」** → 點選其中一種。桌面貓會立即換色；原本收起時也會直接放出，不需重開 App 或編輯 JSON。同一時間仍是一隻貓，依序切換即可。

| 選單名稱 | 著重觀察 |
|---|---|
| 原版黑貓 | 與原本輪廓、大小、動作比較 |
| 黑貓 | 深色底毛與五官 |
| 白貓 | 深色眼睛、嘴巴及白底邊緣 |
| 灰貓 | 耳朵、軀幹與尾巴交界 |
| 橘虎斑 | 額頭、臉頰、側腹與尾環位置 |
| 賓士貓 | 白口鼻、胸腹與四隻白襪 |
| 三花貓 | 雙耳與橘黑拼色位置 |
| 玳瑁貓 | 深色底與橘色斑塊跨姿勢的一致性 |
| 重點色貓 | 臉罩、耳朵、腳掌與尾巴深色區域 |

每一種先看坐姿，點一下看呼嚕，再拖曳抓起、移動、放下；暫停操作約十二秒後看散步、理毛與休息。來回切換兩種毛色，確認沒有殘留前一隻的局部顏色，位置與大小也沒有跳動。最後重開 App，確認仍是最後選擇的毛色。

正在錄音或辨識時，完成後才能換色。錄音、剪貼簿選取、全螢幕、鎖定與休眠仍會暫停桌面貓；驗收散步時請先關閉這些狀態。

若設定了自訂 PNG，錄音浮窗與問候仍優先使用該圖片，桌面貓照常換色。若已手動修改毛色部位或花紋種子，選單會保留自訂資料並提示；未修改的內建 JSON 範例可直接切換。

## 自動驗證與真機驗收的分工

CI 會建置 Apple 晶片／Intel 通用 App 並執行既有離線測試。原生繪圖產物包含九種毛色、每種三十六個抓取影格與十個姿勢，以及錄音浮窗、問候與剪貼簿視窗；可從同一工作的 `macos-cat-native-renders` 下載。

編譯、狀態機測試與原生繪圖不等於已在你的 Mac 完成實際鍵盤操作、其他 App 的貼上、長時間桌面動畫或多螢幕驗收。回報時請附選單的 QA 來源編號、毛色、動作、螢幕縮放，以及截圖或短錄影。

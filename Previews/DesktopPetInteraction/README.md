# 小黑貓滑鼠互動預覽

2026-10-18，依負責人選擇製作的原生 macOS 試玩 checkpoint。

已選定的互動：

- 點一下：閉眼回應，短暫顯示「呼嚕～」。
- 按住拖曳超過 5pt：換成拎起姿勢，跟著這次拖曳移動；放手原處坐下，這次操作不再觸發點擊回應。
- 平常：操作電腦時安靜待機；約 12 秒閒置後才洗臉、散步、打哈欠及休息。
- 滑鼠移動、靠近、經過都不觸發表情或追逐。只接收貓咪圖形範圍內的主動操作，透明留白穿透。

這是獨立預覽，未改動 `Sources/`、正式 `Resources/`、App 版本或安裝位置；沒有安裝、發佈或整合進使用者目前的 YUI Neko。圖片沿用 R6 預覽的原圖和四個原始腳掌輪廓。新增的閉眼、洗臉前腳及拎起姿勢仍待視覺審稿。

目前為 Gemini 補間試玩版。沿用負責人選擇的 Gemini 畫風，由同一 Gemini 對話補畫十六格連續姿勢；本機去背、對齊頭部，再以原坐姿補首尾，共十八張影格。素材在 `GeminiArtwork/`，執行時只播放本機打包圖片。`GeminiArtwork/frame-manifest.json` 記錄原圖雜湊、來源順序及對齊參數，`build_frames.py` 可重跑切分。

提起約 420ms，放下約 220ms；完整拎起走支撐、收腿序列，短拖曳沿當下進度回坐，中途重抓保留當下影格與傾斜。透明視窗擴至 208×192pt 容納垂腿，名義拖曳框仍是 128×128pt，原坐姿和抓取位置保持螢幕座標；留白穿透。只在主動動畫短暫提高更新頻率，其他閒置動作沿用。第一輪幾何補間出現殘影，已捨棄，不包含在試玩 App。

## 試玩

在 repo 根目錄執行：

```sh
Previews/DesktopPetInteraction/build-preview.sh
python3 Previews/DesktopPetInteraction/render-gifs.py
```

用 Finder 開啟 `build/desktop-pet-interaction/小黑貓互動預覽.app`。直接點擊桌面上的貓咪；按住拖曳，放手後觀察是否留在放下的位置。控制視窗的「看洗臉／看散步」可略過閒置等待。「結束預覽」或 Command-Q 會關閉整個預覽。

預覽不寫偏好、Keychain、剪貼簿或貓咪設定，不讀取桌面檔案，不連網，不要求麥克風、螢幕錄製或輔助使用權限。只接收滑鼠位置及自己的點擊／拖曳；不監聽鍵盤內容、不向其他程式送出輸入。鎖定與休眠會隱藏並停止動畫。

## 實作與驗收

`DesktopPetModel` 處理點擊／拖曳判定、放手與取消、跨螢幕限制及閒置循環；`DesktopPetView` 用原 SVG 組圖，使用原生 alpha mask 判斷貓咪可點範圍；`DesktopPetController` 保持面板不可成為 key/main 視窗，透明處讓事件穿透，漏接放手時會在下次 tick 結束拖曳。視窗本身能接收滑鼠，不代表它可以取得鍵盤焦點。

`PreviewTests.swift` 驗證模型、控制器、透明區域、焦點契約、漏接放手、負座標螢幕、移除螢幕、收回／鎖定取消、減少動態效果及十種姿勢的原生渲染。R3 另外驗證提起分段時序、放手首格與最後懸空影格像素一致、中途重新拎起、落地中點擊與減少動態效果切換，並透過實際模型輸出 96 張合成拖曳事件影格。GUI 與手感驗收紀錄另見 `VERIFICATION.md`。GIF 來自這套原生繪圖器的模型事件影格；游標是固定抓取偏移的示意，並非真人操作錄影。`02_拎起放下.gif` 是正常速度，`02b_動作慢看.gif` 是同一批影格的半速播放。

正式整合前仍需接上現有錄音／剪貼簿選取／全螢幕暫停規則，並評估停靠位置與防遮擋；此預覽不讀 Finder、也不修改已安裝程式。多螢幕硬體實測與長時間耗電尚未驗證。未核定的視覺細節以預覽呈現，不當成已上線功能。

負責人可接手的練習：調整 `DesktopPetModel.dragThreshold`，試比較 3／5／8pt 的拖曳起手感；再調整 `pointerUp` 的 1.6 秒回應時間。這兩處分別對應「手勢判定」與「狀態的存續時間」，測試可幫助確認調整沒有讓點擊變成拖曳。

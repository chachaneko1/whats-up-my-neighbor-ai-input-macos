## 已取得的自動驗證證據

### 離線核心與 Windows 平台：309 項通過，0 失敗

- **錄音生命週期：** 每次錄音固定設定與目標快照；開始、收尾與辨識期間取消；過期回覆不能貼上或結束新工作；已知低音量、未知／過期音量、五分鐘上限；兩分鐘暫存到期、新錄音取代及成功交付清理。錄音收尾錯誤、中斷通知順序、連續取消與同步事件重入另有回歸測試。這些使用假錄音來源或受控完成路徑，不能證明實體麥克風音質。
- **Groq 請求：** 使用假 HTTP handler 檢查唯一端點、`whisper-large-v3`、語言、提示、JSON 回應格式、temperature 0 與 WAV 附件內容；驗證 401／403／413／429／5xx、錯誤格式、空回應、取消及過大回應。確認錯誤不回顯伺服器中的測試金鑰；沒有發出真實 API 請求。
- **文字與語言：** 純逐字／標準／簡潔、法律詞彙保護、錨定數字轉換、九種語言的文字系統限制、中英日混合、emoji 與補充平面漢字；主要語言非中文時不套用簡繁轉換。語言限制僅辨識文字系統，不能區分共用拉丁字母的語言。
- **詞典與學習模型：** 200 詞、每詞 40 個 Unicode scalar、500 筆候選、200-byte UTF-8 提示上限；啟停／釘選與提示納入狀態；短詞差異擷取、1.1 秒穩定時間、2 秒取消加入期限、重複通知、變更／取消／到期；原子保存與損壞資料保留。純模型測試通過不代表外部 App 的文字範圍追蹤已驗收。
- **Windows 整合：** Windows 簡繁轉換與斷詞範圍、使用隔離名稱的 Credential Manager 新增／讀取／更新／刪除；快捷鍵衝突回復；設定保存與損壞檔保護；未知目標僅複製、取消先於剪貼簿寫入。

### 受控桌面 UI：93 項通過，0 失敗

已取得跨程序受控視窗的安全貼上證據：擷取可編輯目標、過期快照阻擋貼上、正確目標收到預期文字而未送 Enter、焦點切換阻擋鍵盤注入、密碼欄位拒絕自動貼上，以及停止觀察後不再允許修字學習。

WPF 受控輸入框中，先貼入一句文字，再修正句內單詞；**等長、較長、較短替換**均通過精確插入範圍、修正觀察與重新核對。文字範圍使用 Windows 原生 UI Automation COM 介面，未透過舊版 managed range bridge。

另外保留三種完整插入詞替換案例，以及修改範圍外前文／後文的兩種案例：均確認範圍失效時停止學習、不產生候選且不能重新核對成功。完整選取並替換本次插入文字，可能讓 provider 的端點失去一致性；這是明確的手動新增情境，並未宣稱該操作能自動學習。程式不以讀取整份文件補救。

UI 截圖使用合成資料；100／150／200% 是程式化版面縮放檢查，**不是**已完成真實螢幕 DPI 切換、多螢幕或螢幕閱讀器驗收。最終發布附件另保留逐項結果與畫面。

### 原生安裝、合成前版升級及解除安裝：通過

安裝測試先使用相同 AppId 與**相同程式 payload**製作 `0.0.9-ci` 基準安裝包，再安裝目前的 `0.1.0-beta.1`。這是**合成前版升級測試，不是從歷史正式版本升級**，也沒有證明跨版本資料格式遷移。

測試核對 HKCU 卸載登錄的 `DisplayVersion` 確實更新、安裝位置與每個 payload 檔案的 SHA-256、預設未建立登入啟動值、升級後程式 smoke launch，以及解除安裝移除執行檔與卸載登錄。隔離的合成設定與詞典檔案在升級、啟動及解除安裝後均以雜湊驗證保留。

測試開始前拒絕既有安裝、既有使用者資料及登入啟動值；完成保留驗證後只清理本次建立的測試資料。`0.0.9-ci` 基準安裝包位於暫存目錄，**不包含在交付 `dist` 中**。

## 尚未完成的實機驗收與限制

- Windows 11／Windows 10 22H2 的實體麥克風、USB／藍牙耳機與隱私權拒絕流程。

- 使用者自行建立金鑰後的真實 Groq 辨識、網路錯誤體驗與延遲；沒有真實辨識正確率或即時延遲承諾。
- 消費者版 Windows 10／11 的完整安裝驗收。Server 2022 原生測試能提供 Windows API 證據，但不能取代兩個目標作業系統。
- ARM64；未簽章安裝檔在校園裝置政策與 Windows 信譽防護下的體驗。不得要求使用者關閉系統防護。
- iPhone 接力與多人會議不在本次 Windows 版本範圍；不宣稱與 Mac 全功能對等。

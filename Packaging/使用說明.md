# AI 語音輸入

## 安裝

1. 對 `安裝.command` 按右鍵，選「打開」。
2. 若 macOS 阻擋，前往「系統設定 → 隱私權與安全性」並選「仍要打開」。
3. 依首次啟動畫面按「開啟 Groq API Keys 網頁」，建立自己的 Key。
4. 貼上以 `gsk_` 開頭的 Key，按「安全儲存」。
5. 允許麥克風與輔助使用權限。

## 使用

- 預設按 `Option + ↑` 開始錄音，再按一次停止。
- 點選單列麥克風圖示 →「設定快捷鍵…」，可改成自己的組合。
- App 只會貼上文字，不會替你按 Enter 或送出訊息。
- 若沒有輔助使用權限，文字仍會留在剪貼簿，可手動貼上。

## Groq API Key

- 每位使用者必須使用自己的 Groq API Key。
- Key 只會存進 macOS 鑰匙圈。
- 從選單列選「設定／更換 Groq API 金鑰…」可隨時更新。

## 移除

執行 `移除.command`，會一併刪除 App、登入啟動設定、快捷鍵偏好及 Keychain 中的 Groq API Key。

## 檢查與計畫

基底：正式 v1.4.6 / 1013，cd8065e。安裝中 App 與公開版本均為這版。原先移除回彈的候選只在 macos-stable-landing 未提交工作副本，未進 main 或 Release。該候選為 400ms；本次依使用者要求改為 800ms。原候選工作副本維持原狀。

中等風險：僅改 DesktopPetLift 時序、DesktopPetView 原圖索引、相應 timing metadata 與原生互動測試。沿用 controller → model → lift → view；保留 pickup 前20張、原 source35 坐姿大小、全部36張 PNG、錄音/剪貼簿 busy gate、焦點、透明穿透、取消與 Reduce Motion。其他資料與服務不變。

步驟：正式 tag 基線 → 移除 source27..34 回彈並以每100ms播放 source20..26再35 → 檢查快速放開/重抓/30-120Hz/九色靜止大小 → 全回歸/通用建置 → 同簽章原位置安裝並比對設定。

基線：4086 native interaction checks passed. 後續結果待實際執行後補記。

## 修正驗證

- 原生互動 4728 項通過，包含實際 model 在30/60/120Hz只播放19..26及35，800ms前維持 settling、之後靜止；全部九色 terminal35像素與點尺寸相同；release/re-grab與原生視窗事件既有檢查通過。
- 36張原PNG與正式tag內容逐張SHA-256相同，未套用先前平滑候選。
- `build/landing-800ms.gif` 由同一model的60Hz原生繪圖輸出截取，不是實際使用者滑鼠錄影。
- 公開 latest Release 已讀回仍為 v1.4.6 / 1013；本修正不增加正式版版本號、不觸發公開發布。

完整回歸與通用建置首輪因執行中更新 DesktopPetLift.swift 註解而被 Swift 的 input-file-modified 保護中止；已停止修改輸入檔、從固定檔案重跑。這不屬於測試斷言失敗，不將首輪記成通過。
